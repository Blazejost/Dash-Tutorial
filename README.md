# Dash-Tutorial

## Description
This repository serves as a tutorial for building interactive web applications using the Dash framework. Dash is a productive Python framework ideal for building data visualization interfaces.

## Key Features:
- Learn the basics of Dash, including Layout and Callbacks
- Utilize common HTML and Core components
- Create interactive graphs for data visualization
- Design dashboards with filters
- Explore advanced techniques such as `State` and `PreventUpdate`

## Exercises
- Extend your dashboard with more filters (e.g., date range)
- Build a dashboard for your own CSV data
- Add new chart types (scatter, box)
- Implement a table using `dash_table`
